# Kaitlyn — Portfolio

Static portfolio site (HTML, CSS, JavaScript). No build step.

## Structure
```
index.html
about.html
css/style.css
js/main.js
assets/        <- put your images here
```

## Run locally
Open `index.html` in a browser.

## Deploy with GitHub Pages
1. Push these files to a GitHub repository.
2. Go to Settings → Pages → set Source to your main branch, root folder.
3. Your site will be live at `https://<username>.github.io/<repo>/`.

## Editing
- **Add a project:** copy one `<article class="card">` block in `index.html` and edit it.
- **Use a real image:** in the card, replace the `<svg>` inside `.sleeve` with `<img src="assets/your-image.jpg" alt="Project name">`.
- **Change colours:** edit the variables at the top of `css/style.css`.
- **Contact links:** update the email, LinkedIn and Instagram URLs in the Contact section of `index.html`.
- **About page:** edit `about.html`.
